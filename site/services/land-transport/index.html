Land transport

The road leg stays on the same file as the ocean, air, or warehouse move.

What this solves

Use land transport when the cargo is already, or still needs to be, at a port, airport, or warehouse.

How it is handled

  • Port pickup

    Import boxes leave the terminal on the local office’s truck plan.

  • Airport

    The cartage matches the flight the air desk booked.

  • Warehouse

    Inbound and outbound at Taichung can include the truck.

  • One file

    Status is reported with the rest of the shipment, not as a separate job.

Land transport

Cargo
Import container
Lane
Taichung port to a delivery address in central Taiwan
Challenge
The box has to leave the port and reach a named address on the same file as the ocean move.
Approach
The Taichung office arranges the truck and keeps the status on the shipment file.
Result
The container is picked up at the port and delivered to the address on the file.

The client is not named. This describes the handoff, not an unpublished time or cost figure.
