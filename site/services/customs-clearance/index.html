Customs clearance

Classification first, then the entry. The transport file and the customs file are the same job.

What this solves

Use customs clearance when duty, a permit, or a hold should be known before the cargo arrives.

How it is handled

  • HS code

    The code is checked with the shipper before filing.

  • Import and export

    Entries are filed for cargo moving in or out.

  • Same shipment

    Documents follow the ocean, air, road, or project file.

  • Before arrival

    Questions about duty are raised before the box is on the terminal.
